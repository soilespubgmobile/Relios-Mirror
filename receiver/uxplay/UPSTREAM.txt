UxPlay's AirPlay server library (lib/), from https://github.com/FDH2/UxPlay at commit 05b0275
("video_renderer: fix typo", 6 November 2026). Only lib/ is taken (without lib/dns_sd: the built-in
mdnsd is used), with UxPlay's LICENSE (GPL-3.0; most lib/ files are LGPL-2.1, playfair GPL-3.0).

The files were taken exactly as upstream; ReliosOBS's changes are marked "RELIOS:" in the code
(grep -rn "RELIOS" . lists them). Relios Mirror added, marked the same way: mdnsd_ipv4 and
mdnsd_address_changed (mdnsd/mdnsd.c, mdnsd.h), dnssd_ipv4 and dnssd_address_changed (mdnsd/dnssd_mdnsd.c,
dnssd.h): the address the announcement carries, and whether the computer's address is now another one.
